# CSC494-Dirt_Bike_Maintenance_Sensor_System
The Dirt Bike Sensor Monitor is a simple IoT system designed to help protect your dirt bike’s engine during off-road riding. It uses a small set of sensors to track three critical conditions: oil level, coolant level (for liquid-cooled bikes), and air-box pressure to indicate when the air filter is becoming clogged with dust or mud. The goal is to provide early warnings directly to your phone, allowing you to add oil, top off coolant, or clean the filter before minor issues turn into serious engine damage such as overheating or seizure. By focusing on these essential checks, the system aims to make riding both safer and more convenient.
